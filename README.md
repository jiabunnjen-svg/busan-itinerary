# 🇰🇷 釜山 5 天 4 夜自由行行程導覽 (Busan Travel Itinerary)

一個專為釜山自由行設計的響應式、多分頁互動行程導覽網頁。基於 **Playful Geometric** 設計系統打造，提供清晰的每日行程規劃、行前清單、交通指引與美食購物推薦。

👉 **[點此線上預覽行程網頁](https://jiabunnjen-svg.github.io/busan-itinerary/)**

---

## 🌟 網頁特色

- 📌 **頂部固定導覽 (Sticky Navigation)**：分頁列固定於螢幕上方，隨時可秒切換至不同日期或頁面。
- 📋 **行前準備 Checklist**：整合護照、Q-Code、膠囊列車/SPA LAND 預約憑證、Naver Map/Kakao T 等必備 App 與保暖裝備提醒。
- 🗓️ **精確每日 Timeline**：詳細記錄每日景點時間、交通時間 (Naver Map 對照) 與注意事項。
- 🛒 **當日推薦購物與美食**：每日分頁底部獨立整理出當天必吃的道地小吃與推薦購買清單。
- 📱 **響應式設計 (Responsive Design)**：完美支援手機、平板與電腦端瀏覽，隨手查閱極便利。
- 🖨️ **友善列印功能**：支援一鍵匯出為 PDF 或列印實體紙本。

## 🧳 行程概覽 (Itinerary Overview)

* **Day 1 (1/8 五)**：抵達釜山 ➔ 廣安里海灘散步與夜景 ➔ Millac The Market
* **Day 2 (1/9 六)**：海東龍宮寺 ➔ 海雲台商圈 ➔ SPA LAND 五星汗蒸幕 ➔ 廣安里無人機秀
* **Day 3 (1/10 日)**：天空膠囊列車 (尾浦➔青沙浦) ➔ 青沙浦踏石展望台 ➔ Palate 米其林美饌 ➔ 青沙浦烤貝
* **Day 4 (1/11 一)**：田浦選物店與咖啡街 ➔ 西面地下街 & Olive Young 購物 ➔ 釜山宅韓式烤肉
* **Day 5 (1/12 二)**：南浦洞 (BIFF 廣場 & 富平市場) ➔ 水邊最高豬肉湯飯 ➔ 金海機場返台
